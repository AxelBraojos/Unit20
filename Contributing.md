# CONTRIBUTING

Este repositorio forma parte del Assignment Brief de la Unit 20 y está centrado en el desarrollo de una aplicación TypeScript para el análisis de precios de combustibles.
El objetivo del proyecto es mantener una estructura clara, modular y fácil de mantener, aplicando principios SOLID y prácticas de Clean Code.

# Requisitos previos

Antes de trabajar con el proyecto es recomendable tener instalado:

- NodeJS
- npm
- Git
- Visual Studio Code


# Instalación del proyecto

## 1. Clonar el repositorio


git clone + url del repositorio


## 2. Entrar en la carpeta del proyecto


cd Unit-20-


## 3. Instalar dependencias


npm install




# Compilar el proyecto


npm run build




# Ejecutar la aplicación


npm run start




# Ejecutar los tests


npm test

Antes de realizar un commit es recomendable comprobar que:

- el proyecto compila correctamente,
- todos los tests pasan,
- no existen errores de TypeScript.




# Normas generales de desarrollo

Durante el desarrollo del proyecto se intenta mantener una estructura sencilla y mantenible.

Por este motivo es recomendable

- utilizar nombres claros y descriptivos,
- evitar clases demasiado grandes,
- separar responsabilidades entre servicios,
- evitar código duplicado,
- mantener funciones pequeñas,
- usar control de errores mediante excepciones,
- escribir tests para la lógica importante.


# Tests

Los tests unitarios deben centrarse en métodos públicos y cubrir los casos más importantes de la lógica de negocio.









# Objetivo del proyecto

El objetivo principal del proyecto es practicar:

- programación orientada a objetos,
- principios SOLID,
- Clean Code,
- testing automatizado,
- y organización de proyectos TypeScript.
